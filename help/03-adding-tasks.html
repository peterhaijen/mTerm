Adding Tasks

mTerm reads tasks from markdown files in the folder selected with Tasks > Select Tasks Directory....

  • Add the tag mterm to include a file in the Tasks menu.
  • The menu title uses description when present.
  • Without description, mTerm uses the filename without .md.
  • Commands are read only from fenced bash code blocks and sent to the active terminal.
  • If more than one terminal has broadcast enabled, the task is sent to those terminals too.
  • Frontmatter properties named like <name> prompt for a value before the task runs and export shell variable name.
  • Use shell variables in commands, for example $name or ${name:-default}.
  • Use <name:-default> in frontmatter to set a default value for exported variable name.
  • Use <name:?message> to require a value and show message while it is empty.

Example

---
tags:
  - mterm
description: Deploy branch
<remote_branch:?Remote branch is required>: The remote branch to deploy
<remote:-origin>: Remote name
<flags>: Optional extra flags
<environment>: Optional environment
---

```bash
git push "$remote" "$remote_branch" $flags
./deploy "${environment:-staging}"
```
