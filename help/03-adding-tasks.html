Adding Tasks

mTerm reads tasks from markdown files in ~/vault33.

  • Add the tag mterm to include a file in the Tasks menu.
  • The menu title uses description when present.
  • Without description, mTerm uses the filename without .md.
  • Commands are read only from fenced bash code blocks and sent to the active terminal.
  • If more than one terminal has broadcast enabled, the task is sent to those terminals too.

Example

---
tags:
  - mterm
description: Update, upgrade en autoremove
---

```bash
sudo apt update
sudo apt upgrade
sudo apt autoremove
```
