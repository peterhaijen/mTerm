Adding Hosts

mTerm reads hosts from ~/.ssh/config.

  • Only Host blocks marked with # mTerm are added to the Terminals menu.
  • Groups are used to build nested submenus under Terminals.
  • Wildcard entries like Host * are ignored.

Example

Host webserver
  # mTerm Groups Webserver
  Hostname 10.0.0.11

# Multiple groups:
Host appserver
  # mTerm Groups VPS Webserver
  Hostname 10.0.0.12
