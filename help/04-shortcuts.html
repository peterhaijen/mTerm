Shortcuts

  • Alt+Shift+Right: next tab in tabs view, or next terminal in tile view.
  • Alt+Shift+Left: previous tab in tabs view, or previous terminal in tile view.
  • Alt+Shift+Space: toggle broadcast for the current terminal.
  • Alt+Shift+Delete: close the current terminal.
  • Ctrl+Insert: copy selected terminal text.
  • Alt+Shift+Insert: copy selected terminal text to the AI terminal and focus it.
  • Shift+Insert: paste clipboard text into the current terminal.
  • Ctrl+Shift++: increase terminal font size.
  • Ctrl+-: decrease terminal font size.
  • Ctrl+0: reset terminal font size.
  • Click terminal checkbox: toggle broadcast for that terminal.
  • Alt+Shift+Click terminal checkbox: set all checkboxes to the same state.
