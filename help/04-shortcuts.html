Shortcuts

  • Ctrl+Right: next tab in tabs view, or next terminal in tile view.
  • Ctrl+Left: previous tab in tabs view, or previous terminal in tile view.
  • Ctrl+Space: toggle broadcast for the current terminal.
  • Ctrl+Delete: close the current terminal.
  • Click terminal checkbox: toggle broadcast for that terminal.
  • Ctrl+Click terminal checkbox: set all checkboxes to the same state.
